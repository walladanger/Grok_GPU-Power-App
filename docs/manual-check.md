# Manual checklist

Run these checks on this PC. They change a live power limit or blank the screen.

The automatic suite does not perform a reinstall or a rollback.

- [ ] Apply a limit and read it back.
- [ ] Cancel the administrator prompt and confirm the limit stayed.
- [ ] Confirm a saved limit returns after the display driver comes back.
- [ ] Resize the dashboard and a popped-out graph.
- [ ] Record a few seconds and open the file.
- [ ] Check the three tray modes and the hover text.
- [ ] Run one reinstall or rollback only when the operator chooses.
